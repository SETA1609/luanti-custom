# Android Build and Platform Setup

This directory contains the Gradle build configuration, platform resources, Java interface code, and native integration scripts for the Android version of Luanti (formerly Minetest).

---

## How Each File in this Directory Works

### `build.gradle`
This is the root-level Gradle build configuration file. It defines build dependencies, plugins, and repos (such as Maven and Google) that Gradle will use to compile the Android app. It establishes target versions for Gradle plugins and compiles components.

### `settings.gradle`
This file defines the project name (`settings.gradle` sets the project name to `:app` or imports `:app`) and includes the `:app` module, telling Gradle which directories are part of the multi-project build setup.

### `gradle.properties`
This file configures settings for the Gradle build execution itself. It typically sets default JVM memory configurations (e.g. `org.gradle.jvmargs=-Xmx2048m`), enables the AndroidX support libraries, and configures daemon options to speed up compile times.

### `gradlew` and `gradlew.bat`
These are the Gradle Wrapper scripts (`gradlew` for Unix-like systems and `gradlew.bat` for Windows). They ensure that anybody building the project uses the exact same Gradle version designated by the project, downloading it automatically if it is not present in the developer's system cache.

### `keystore-minetest.jks`
This is a Java Keystore (JKS) binary file. It holds the private cryptographic keys and certificate chains used to sign the Android application package (`.apk` or `.aab`) so that it can be installed, verified, and updated on Android devices.

### `SDL_Java_RMB_fix.patch`
This patch file contains direct code modifications for the Simple DirectMedia Layer (SDL) Java source codebase. It is applied during compilation to fix a specific input bug where Right Mouse Button (RMB) events generated by auxiliary mice or touch inputs were incorrectly processed or ignored on Android devices.

---

## How Subdirectories Work

- **`app/`**: Contains the core Android Java/Kotlin source files, resource configurations (like strings, layout XMLs), manifest files (`AndroidManifest.xml`), and the app-level `build.gradle` specifying SDK versions, compile settings, and signing configs.
- **`gradle/`**: Holds the `gradle-wrapper.jar` and `gradle-wrapper.properties` that specifies the version of Gradle downloaded by `gradlew`.
- **`icons/`**: Stores various mipmap density graphical assets (launcher icons, round icons, banner icons) used by Android launchers.
- **`native/`**: Houses the JNI (Java Native Interface) bridge code enabling the C++ game engine core to communicate with the Android operating system features (such as audio, touch events, storage, lifecycle states, and camera).
